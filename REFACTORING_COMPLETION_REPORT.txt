ORGANIZATION PRINCIPLES
-----------------------

1. Separation of Concerns
   - Each module handles a specific concern
   - opencv_upscaler: OpenCV-based upscaling
   - amf_upscaler: AMD AMF-based upscaling
   - h264_encoder: AMF H.264 encoding
   - frame_cache: Frame caching and storage management
   - constants: Shared configuration

2. Code Reusability
   - Frame cache can be used by other processing pipelines
   - Constants can be referenced by any consumer
   - Upscalers and encoders are independent

3. Maintainability
   - Smaller files are easier to understand
   - Changes to one component don't affect others
   - Clear module boundaries

4. Scalability
   - Easy to add new upscalers (create new module)
   - Easy to add new encoders (create new module)
   - Main module stays focused on coordination

5. Testability
   - Each class can be unit tested independently
   - Mock dependencies are clearer
   - Integration tests easier to organize
